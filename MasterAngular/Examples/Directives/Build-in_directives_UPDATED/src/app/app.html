if() Binding

If isActive is true, app-item-detail component will render:

@if(isActive){ }

If currentCustomer variable isn't null, say hello to Laura:

@if(currentCustomer){
Hello, {{currentCustomer.name}}
}

nullCustomer variable is null by default. if() guards against null. Give it a value to show it:

@if(nullCustomer){
Hello, {{nullCustomer}}
}
